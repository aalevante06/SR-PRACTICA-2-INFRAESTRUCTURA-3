# Scripts y comandos de apoyo

- `web-server-services-setup.sh`: instala y habilita Apache2/HTTPS y OpenSSH Server.
- `test-pc-user.sh`: comprueba HTTPS público y el bloqueo de SSH directo.
- `test-vpn-client.sh`: levanta la VPN, muestra estado/ruta y ejecuta la prueba SSH.
- `switch-setup.txt`: VLAN 10, trunk y puerto de acceso del switch.
- `r-cisco-critical-config.txt`: NAT/PAT, publicación HTTPS, interfaces y ACL crítica del Cisco.

Las credenciales reales no están incluidas. Los algoritmos DES/SHA1/IKEv1 de esta práctica se conservaron por compatibilidad con el entorno de laboratorio y **no son una recomendación para producción**.
